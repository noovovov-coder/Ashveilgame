# Как запустить Ashveil (прототип)

## Требования

- **Unity 6** (6000.x) — установить через Unity Hub: https://unity.com/download
- Git (проект уже склонирован, если ты это читаешь)

## Запуск за 5 минут

1. **Unity Hub → Add → выбрать папку репозитория** (`Ashveilgame`).
   Unity создаст служебные папки и подтянет пакеты из `Packages/manifest.json`
   (URP, Input System, Cinemachine, AI Navigation, FishNet с OpenUPM).
   Первый импорт занимает несколько минут.

2. **Включить новый Input System** (если Unity спросит — согласиться и перезапустить):
   Edit → Project Settings → Player → Other Settings → Active Input Handling →
   **Input System Package (New)**.

3. **Создать сцену с бутстрапом:**
   - File → New Scene (Basic или Empty)
   - GameObject → Create Empty, назвать `Bootstrap`
   - Add Component → **Game Bootstrap** (скрипт `Ashveil.Core.GameBootstrap`)
   - File → Save As → `Assets/Scenes/Prototype.unity`

4. **Нажать Play.** Скрипт сам сгенерирует мир: процедурный рельеф,
   деревья/камни, врагов, босса, очаг с кузницей, камеру и HUD.

## Управление

| Действие | Клавиша |
|----------|---------|
| Движение / спринт | WASD / Shift |
| Камера | Мышь (Esc — освободить курсор) |
| Атака (комбо ×3) | ЛКМ — также рубит деревья и камни |
| Парирование | ПКМ (окно 0.18 с, ошеломляет врага) |
| Уклонение (i-фреймы) | Пробел |
| Инвентарь | I |
| Карта (туман войны) | M |
| Строительство | B (1–3 выбор, ЛКМ поставить, R поворот) |
| Сломать постройку | X + ПКМ (возврат 50% материалов) |
| Крафт | E у кузницы (тёмный куб рядом со спауном) |
| Сохранить мир | F5 (JSON, загрузка автоматическая при старте) |

## Что есть в прототипе

- **Бой**: комбо, стамина, уклонение, парирование; враги телеграфируют атаки.
- **Босс**: Гнилой Пастырь в дальнем углу карты (фиолетовый колосс).
  Две фазы: яд + ритуал призыва. Скейлится по числу игроков. Дроп: эпик + легендарка.
- **Мир**: процедурный рельеф по сиду, добыча ресурсов, туман войны.
- **База**: очаг (замедляет врагов, лечит игроков), кузница (3 рецепта),
  строительство стен/полов по сетке.
- **Налёты**: каждые ~5 минут волна заражённых идёт на очаг (предупреждение за 60 с).
- **Сохранения**: сид мира, ресурсы, инвентарь, постройки —
  `%userprofile%/AppData/LocalLow/<Company>/<Product>/ashveil_world.json`.
  Удалить сейв = новый мир.

## Кооп (отдельная сцена)

Сетевой слой готов (FishNet), но требует ручной сборки сцены —
см. `docs/coop-setup.md`. Соло-прототип работает без сети.

## Известные ограничения

- Вся графика — примитивы (капсулы/кубы); арт-пайплайн (Blender) — позже.
- Если FishNet не скачался с OpenUPM, соло-режим всё равно работает:
  сетевой код изолирован в отдельную сборку `Ashveil.Network`.
- UI на OnGUI — временный, для отладки.

## Куда вносить правки

| Что менять | Файл |
|------------|------|
| Урон/комбо/перекаты игрока | `Assets/Scripts/Player/PlayerCombat.cs` (поля в инспекторе) |
| Скорость/стамина | `PlayerController.cs`, `PlayerStamina.cs` |
| Поведение врага | `Assets/Scripts/Enemies/EnemyAI.cs` |
| Фазы и урон босса | `Assets/Scripts/Enemies/Bosses/RottenShepherd.cs` |
| Состав мира (число врагов, деревьев) | `GameBootstrap` — поля в инспекторе |
| Рецепты крафта, предметы, каталог построек | `GameBootstrap.cs` (CreateItems, BuildCatalog, CreateBase) |
| Размер/рельеф мира | `Assets/Scripts/World/TerrainGenerator.cs` |
