# Первый босс + лут — сборка

Этап roadmap «Первый босс + лут»: Гнилой Пастырь с двумя фазами, инвентарь.

## Предметы (ScriptableObject)

**Assets → Create → Ashveil → Item.** Создать в `Assets/Items/`:

| Ассет | Редкость | Слот | Примечание |
|-------|----------|------|------------|
| RustedBlade | Common | Weapon | дроп с заражённых |
| BogTrinket | Rare | Amulet | дроп с заражённых (низкий шанс) |
| RottingRitualStaff | Epic | Weapon | «Посох Гниющего Ритуала», босс |
| ShepherdMask | Legendary | Head | «Маска Пастыря» — в `Unique Effect` описать: «яд вокруг лечит союзников» |

## Префаб пикапа

1. Небольшая Sphere (scale 0.4), материал по вкусу.
2. Компонент `ItemPickup` (SphereCollider станет триггером автоматически).
3. Сохранить как `Assets/Prefabs/ItemPickup.prefab`.

## Игрок

Добавить компонент `Inventory` на префаб игрока.

## Ядовитое облако

1. Sphere (scale 1), убрать коллайдер, полупрозрачный зелёный материал.
2. Компонент `PoisonCloud`.
3. Префаб `Assets/Prefabs/PoisonCloud.prefab`.

## Босс

1. Capsule (scale 2×2×2), имя `RottenShepherd`, поставить в дальнюю часть арены на NavMesh.
2. Компоненты:
   - `NavMeshAgent` (speed 2.5 — он медленный колосс, stopping distance 2)
   - `Health` (Max 600 — пересчитается при активации по числу игроков)
   - `RottenShepherd`: назначить `PoisonCloud Prefab`, `Add Prefab` (префаб Infected)
   - `LootDropper`: pickupPrefab + таблица
     - RottingRitualStaff — guaranteed
     - ShepherdMask — chance 0.5 (потом отбалансим)
3. Рядовым врагам (Infected) тоже добавить `LootDropper`:
   - RustedBlade — chance 0.3
   - BogTrinket — chance 0.05

## UI

На объект `Debug HUD` добавить `InventoryHud` и `BossHealthBar`.

## Что проверять

- Босс активируется при подходе на 15 м, HP скейлится по числу игроков
  (+40% за второго — таблица GDD §5).
- Фаза 1: медленные размашистые удары (замах 0.9 с) + споры под случайным игроком
  каждые ~7 с. Облако растёт 6 с, первая секунда — телеграф без урона.
- На 50% HP — фаза 2 «Ритуал»: босс кастует 2 с (окно для бурста), призывает
  2 заражённых. Не убили за 20 с — сливаются с боссом, +8% HP боссу за каждого.
- Парирование боссу урон прерывает, но НЕ ошеломляет (в отличие от рядовых).
- Лут: с босса гарантированно падает эпик, легендарка с шансом; подбор касанием.
- Инвентарь: клавиша `I`, цвета редкости — белый/синий/фиолетовый/оранжевый.

## Сеть

Боссу добавить `NetworkObject`, `NetworkTransform`, `NetworkHealth` — урон
пойдёт через хоста так же, как у рядовых врагов. ИИ босса работает только
у хоста (по аналогии с `NetworkEnemy`; отдельная обёртка — следующий этап).
