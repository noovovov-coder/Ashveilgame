# Ashveil

**Жанр:** Dark Fantasy Co-op Action RPG  
**Платформа:** PC (Steam)  
**Игроки:** 1–4 (кооператив)  
**Перспектива:** Третье лицо  
**Движок:** Unity 6 + URP

---

## Концепция

> "Выжить можно в одиночку. Победить — только вместе."

Мир Ашвейл поглощает Серый Пепел — древнее проклятье, превращающее живых в чудовищ. Пятый бог Ашс разорвал цикл смерти, удерживая души умерших. Игроки — последние **Искровые**: редкие люди с остатком божественной Искры в крови, способные сражаться с заражением.

---

## Столпы геймплея

| Столп | Описание |
|-------|----------|
| **Бой** | Весомый, требует позиционирования. Уклонение, парирование, комбо. |
| **Исследование** | Процедурные зоны, туман войны, мини-данжи, случайные события. |
| **Лутинг** | 4 тира редкости, универсальные предметы, легендарки только с боссов. |
| **База** | Общая крепость для команды. Свободное строительство, 10 крафт-станций. |

---

## Классы

- **Пеплокрад** — ближний бой, инициатор, поглощает Пепел врагов
- **Гасильница** — магия льда, заморозка, поддержка команды
- **Костяной Вестник** — некромантия, призыватель, контроль зон
- **Скиталец** — дальний бой, разведка, ловушки

---

## Боссы

1. **Гнилой Пастырь** — Болотные катакомбы
2. **Дева Белой Бури** — Ледяные руины
3. **Трое Без Лица** — Затопленный храм
4. **Архипастырь Пепла** — Пепловые равнины
5. **Сердце Пепла** — Ядро проклятья (финал)

---

## Быстрый старт

Открыть папку в Unity 6 → пустая сцена → пустой объект → компонент
**GameBootstrap** → Play. Мир соберётся сам.
Подробно: [docs/how-to-run.md](docs/how-to-run.md)

## Структура проекта

```
Assets/Scripts/
├── Core/       — GameBootstrap (сборка сцены), камера
├── Combat/     — здоровье, урон, интерфейсы боя
├── Player/     — движение, бой, стамина, ввод
├── Enemies/    — ИИ рядовых врагов и боссов
├── Items/      — предметы, инвентарь, лут, ресурсы
├── Building/   — строительство, очаг
├── Crafting/   — крафт-станции, база предметов
├── World/      — процедурный рельеф, туман войны, налёты
├── SaveLoad/   — JSON-сохранения
├── Network/    — кооп (FishNet, отдельная сборка)
└── UI/         — отладочный HUD
docs/           — инструкции по запуску и сборке сцен
```

## Технический стек

- **Движок:** Unity 6 + URP
- **Сеть:** FishNet + Steam Relay (Steamworks.NET)
- **Звук:** FMOD
- **ИИ:** NavMesh + Behavior Designer
- **Процедурная генерация:** Wave Function Collapse
- **3D:** Blender + Substance Painter
